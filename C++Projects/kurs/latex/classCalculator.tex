Вычисляет сумму элементов вектора с обработкой переполнения 

Функция вычисляет сумму всех элементов вектора 16-\/битных беззнаковых целых чисел. Для предотвращения переполнения используется 64-\/битная арифметика, а результат приводится к 16-\/битному типу, что эквивалентно взятию остатка от деления на 65536.


\begin{DoxyParams}{Аргументы}
{\em vector} & Вектор 16-\/битных беззнаковых целых чисел \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Возвращает}
Сумма элементов вектора по модулю 65536 (тип uint16\+\_\+t)
\end{DoxyReturn}
\begin{DoxyNote}{Заметки}
Для вектора из 1000 элементов со значением 10000 каждый\+: 1000 $\ast$ 10000 = 10000000 10000000 \% 65536 = 11000 
\end{DoxyNote}
\begin{DoxyWarning}{Предупреждения}
Максимальное значение uint16\+\_\+t\+: 65535 (0x\+FFFF) 
\end{DoxyWarning}
