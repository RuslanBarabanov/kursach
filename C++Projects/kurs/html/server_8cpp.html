Подробное описание

Реализация сервера для вычисления суммы векторов

Данный файл содержит реализацию сервера, который принимает подключения от клиентов, аутентифицирует их, получает векторы чисел и вычисляет их суммы с обработкой переполнения.

Разбирает аргументы командной строки

Функция обрабатывает параметры командной строки и заполняет структуру ServerParams. Поддерживаемые опции: -h/–help, -a/–auth, -l/–log, -p/–port.

Аргументы
argcКоличество аргументов
argvМассив аргументов
paramsСтруктура для хранения параметров сервера
Возвращает
true если разбор успешен, false в случае ошибки или запроса справки
Заметки
При указании -h или –help функция выводит справку и возвращает false
