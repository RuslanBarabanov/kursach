Аутентифицирует пользователя по логину, соли и хешу

Функция проверяет аутентификационные данные пользователя, вычисляя SHA224 хеш от комбинации соли и пароля, и сравнивает его с предоставленным хешем.

Аргументы
loginЛогин пользователя (должен быть "user" после очистки пробелов)
passwordПароль (не используется, захардкожен как "P@ssW0rd")
saltСоль для хеширования (16 байт)
hashОжидаемый хеш пароля (56 байт в hex)
Возвращает
true если аутентификация успешна, false в случае ошибки
Заметки
Хеш вычисляется как SHA224(salt + "P@ssW0rd") в верхнем регистре
Предупреждения
Пароль захардкожен и должен совпадать с паролем в клиенте

◆ loadFromFile()

bool AuthDatabase::loadFromFile ( const std::string &  filename)

Загружает базу данных аутентификации из файла

Функция читает файл в формате "логин:пароль" и заполняет внутреннюю карту пользователей. Каждая строка файла должна содержать логин и пароль, разделенные двоеточием.

Аргументы
filenameИмя файла с данными аутентификации
Возвращает
true если файл успешно загружен, false в случае ошибки
Исключения
Невыбрасывает исключения, ошибки логируются в stderr
